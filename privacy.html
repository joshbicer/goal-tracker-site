Privacy Policy

Effective November 9, 2026.

Personal Goal Tracker is a private tool used only by its developer. It requests read-only access to the developer's own Google Health data (activity and fitness, health metrics) through Google OAuth.

  • Data accessed: daily step counts and exercise sessions.
  • Use: the data is written only to the developer's own Google Sheet.
  • Storage and sharing: data is not sold, shared, or disclosed to any third party. OAuth tokens are stored only on the developer's own computer.
  • Google user data use adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion: access can be revoked at any time at myaccount.google.com/permissions.
